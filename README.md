## Technical Principles

- **Zero dependencies & build steps:** Pure HTML5, CSS3, and modern vanilla JavaScript. No npm modules, bundlers, or frameworks.
- **Zero third-party trackers:** No Google Analytics, tracking pixels, or third-party cookies. Only local preferences stored.
- **Performance & Core Web Vitals:** Idle-throttled animation loops, optimized font loading, IntersectionObserver triggers, and low layout shifts.
- **Accessibility (A11y):** Keyboard navigation traps on modal drawers, WCAG-compliant color contrast, semantic landmarks, and full ARIA accordion states.
- **Schema & SEO:** Standardized JSON-LD graph (`Organization`, `Person`, `WebSite`, `WebPage`, `BreadcrumbList`, `Service`, `Offer`).
- **Progressive enhancement:** Fully functional without JavaScript enabled.
